ascii-renderer

About This Project

Self-explanatory, really.

This is meant as an exercise for me to understand the rendering pipeline and how to render basic 3D scenes. The end result will be a renderer within the terminal that can render wireframes, objects, whatever, using ASCII characters.

Turns out part of this project is also creating a basic graphics library to perform all of the computation needed to properly display and rasterize objects in a scene. Which I only realized once I started working on this and seeing that I was just creating basic graphics operation interfaces. I am rly trying, ok...
